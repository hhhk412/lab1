## Описание проекта

Программа представляет собой простую анимацию космического неба с приближающимися звёздами в 2D

## Запуск:

Версия Python - 3.14

### Для Windows:
```bash
python -m venv venv
source venv/Scripts/activate
pip install -r requirements.txt
python main.py
```

### Для Linux / macOS:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 main.py
```
