## Описание проекта
Программа представляет собой интерактивную графическую симуляцию полёта сквозь космическое пространство. Эффект трёхмерного движения реализован путём перспективной проекции 3D-координат звёзд (X, Y, Z) на двухмерную плоскость экрана. Размер объектов и скорость их приближения динамически рассчитываются на основе удалённости от наблюдателя.

## Функциональные возможности

### Основной функционал
 Анимация движения сквозь трёхмерное звёздное поле (250 звёзд).
 Звёзды разных размеров и пяти случайных цветов.
 Реализация 3D-пространства: размер и скорость звезды зависят от расстояния до неё (координаты Z).

### Дополнительный функционал
 Регулировка скорости движения с клавиатуры.
 Регулировка направления полёта с помощью перемещения мыши.

## Требования к системе
- **Python:** 3.12 или выше
- **Операционная система:** Windows / macOS / Linux
- **Библиотеки:** Используются только стандартные встроенные пакеты Python (`tkinter`, `random`).

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd lab1
```

### 2. Создание и активация виртуального окружения
* **Windows (PowerShell):**
  ```bash
  python -m venv .venv
  .venv\Scripts\Activate.ps1
  ```
* **macOS / Linux:**
  ```bash
  python3 -m venv .venv
  source .venv/bin/activate
  ```

### 3. Установка dependencies
```bash
pip install -r requirements.txt
```

### 4. Запуск программы
```bash
python main.py
```

### 5. Управление
* **Стрелка вверх** — увеличить скорость полёта.
* **Стрелка вниз** — уменьшить скорость полёта.
* **Движение мыши** — изменить направление полёта (смещение камеры относительно центра).
